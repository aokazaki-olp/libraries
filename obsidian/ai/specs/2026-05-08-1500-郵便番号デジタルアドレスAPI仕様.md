# API Reference for 郵便番号・デジタルアドレス (1.0.2.260209)

ベースURL: `https://api.da.pf.japanpost.jp`

> [!info] 概要
> - 郵便番号・デジタルアドレスAPIは、デジタルアドレスコアシステムへのアクセスを提供します。
> - トークン発行やデジタルアドレス、郵便番号、事業所個別郵便番号の検索などの機能を提供します。
> - ※本APIでは、レスポンスオブジェクトのキーは必ず返却されますが、値が存在しない場合は `null` を設定して返却します。

> [!note] 認証
> Bearer JWT トークン — `Authorization: Bearer {トークン}`

## searchcode V2

郵便番号、事業所個別郵便番号、デジタルアドレスの共通検索

### GET /api/v2/searchcode/{search_code}

**コード番号検索 V2 (1-1034)**

郵便番号、事業所個別郵便番号、デジタルアドレスの統一検索エンドポイント。いずれかを指定して検索を行い、住所情報を返す。検索時に、ページ番号や取得件数を指定。指定がない場合はデフォルト値が適用される。

パラメーター:
- `page`: ページ番号 (デフォルト値:1)
- `limit`: 取得する最大レコード数 (デフォルト値:1000、最大値:1000)
- `choikitype`: 返却する町域フィールド (指定がない場合は choikitype=1 とみなす)
  - `1`: 括弧なし
  - `2`: 括弧あり
- `searchtype`: 検索対象 (指定がない場合は searchtype=1 とみなす)
  - `1`: 郵便番号、事業所個別郵便番号、デジタルアドレスを検索
  - `2`: 郵便番号、デジタルアドレスを検索

> [!tip] 認証
> token (Bearer JWT) — **required**

#### Path パラメーター

| パラメーター | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| search_code | required | string | 郵便番号 (3桁以上の数値。7桁未満の場合は前方一致パターン検索) / 事業所個別郵便番号 / デジタルアドレス |

#### Query パラメーター

| パラメーター | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| page | - | number | ページ番号 (デフォルト値:1) |
| limit | - | number | 取得最大レコード数 (デフォルト値:1000、最大値:1000) |
| ec_uid | - | string | プロバイダーのユーザーID (クエリパラメーター) |
| choikitype | - | number | 返却するフィールドを指定 (未指定時は1とみなす) `1`:括弧無し / `2`:括弧有り |
| searchtype | - | number | 検索方法を指定 (未指定時は1とみなす) `1`:郵便番号・事業所個別・デジタルアドレス / `2`:郵便番号・デジタルアドレスのみ |

#### レスポンス

| ステータス | 説明 |
| --- | --- |
| 200 | 検索した郵便番号、事業所個別郵便番号、デジタルアドレスの情報を返す。データが無い項目は `null` をセットして返す。 |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 500 | Internal Server Error |

## addresszip V2

住所の一部から該当する住所を検索

### POST /api/v2/addresszip

**住所から郵便番号を検索 V2 (1-1035)**

住所の一部から該当する郵便番号・住所情報を検索。

- 住所から該当する郵便番号を返す
- マッチングレベルに応じたデータを返す
- リクエストのデータタイプを添えてリクエストすること。データタイプは下記が該当
  - コード (pref_code など)
  - 名称 (pref_name など)
  - カタカナ
  - ローマ字
  - フリーワード
- パラメータについての注意
  - `page` でページ番号を指定し、`limit` でレスポンスの最大取得件数を指定可能
  - `page` と `limit` が省略された場合は、デフォルト値 (page=1, limit=1000) が適用される
  - `pref_code` と `pref_name` が両方リクエストされた場合は、`pref_code` が優先される
  - `city_code` と `city_name` が両方リクエストされた場合は、`city_code` が優先される

> [!tip] 認証
> token (Bearer JWT) — **required**

#### Query パラメーター

| パラメーター | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| ec_uid | - | string | プロバイダーのユーザーID (クエリパラメーター) |

#### リクエストボディ (application/json — required)

| フィールド | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| pref_code | - | string | 都道府県コード |
| pref_name | - | string | 都道府県名 |
| pref_kana | - | string | 都道府県名カナ |
| pref_roma | - | string | 都道府県名ローマ字 |
| city_code | - | string | 市区町村コード |
| city_name | - | string | 市区町村名 |
| city_kana | - | string | 市区町村名カナ |
| city_roma | - | string | 市区町村名ローマ字 |
| town_name | - | string | 町域 |
| town_kana | - | string | 町域カナ |
| town_roma | - | string | 町域ローマ字 |
| freeword | - | string | フリーワード |
| flg_getcity | - | number | 市区町村一覧のみ取得フラグ (デフォルト値:0、0:すべて取得、1:市区町村のみ取得) |
| flg_getpref | - | number | 都道府県一覧のみ取得フラグ (デフォルト値:0、0:すべて取得、1:都道府県のみ取得) |
| page | - | integer | ページ数 (デフォルト値:1) |
| limit | - | integer | 取得最大レコード数 (デフォルト値:1000、最大値:1000) |

#### リクエスト例

```json

  "pref_code": "13",
  "city_code": "13102",
  "flg_getcity": 0,
  "flg_getpref": 0,
  "page": 1,
  "limit": 100
}
```

#### レスポンス

| ステータス | 説明 |
| --- | --- |
| 200 | 検索した住所、マッチングレベル、郵便番号を返す |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |

> - `1`: 都道府県レベルで一致
> - `2`: 市区町村レベルで一致

## token V2

事業者が郵便番号・デジタルアドレスAPIを利用するのに必要なトークンを取得

### POST /api/v2/j/token

**API利用トークンの取得 V2 (1-1033)**

OAuth2.0における grant_type が `client_credentials` に基づいてトークンリクエストに対してAPI利用のトークンを返す。grant_type とともに、組織およびシステム登録で事前に取得しているクライアントIDとシークレットキーを指定してリクエストし、検証結果が問題ない場合はJWT形式のトークンを返却。

#### Header パラメーター

| パラメーター | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| x-forwarded-for | required | string | 送信元IPアドレス |

#### リクエストボディ (application/json — required)

| フィールド | 必須 | 型 | 説明 |
| --- | --- | --- | --- |
| grant_type | required | string | 「client_credentials」で固定 |
| client_id | required | string | クライアントID |
| secret_key | required | string | シークレットキー |

#### リクエスト例

```json
{
  "grant_type": "client_credentials",
  "client_id": "TEST7t6fj7eqC5v6UDaHlpvvtesttest",
  "secret_key": "testGzhSdzpZ1muyICtest0123456789"
}
```

#### レスポンス

| ステータス | 説明 |
| --- | --- |
| 200 | token情報を返します。 |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 500 | Internal Server Error |

#### レスポンスボディ (200) — jtokenRes

```json
{
  "scope": "J1",
  "token_type": "jwt",
  "expires_in": 123456,
  "token": "{アクセストークン}"
}
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| token | string | アクセストークン |
| token_type | string | トークンタイプ |
| expires_in | integer | 有効秒数 |
| scope | string | スコープ |
