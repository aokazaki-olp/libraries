# gBizINFO API クライアント

## gBizINFO とは

経済産業省が提供する法人情報公開API。法人番号・法人名・補助金交付情報等を返す。

- ベースURL: `https://info.gbiz.go.jp/hojin/v1`
- 認証: APIトークンを **`X-hojinInfo-api-token`** カスタムヘッダで送る（Bearer ではない）
- レスポンス: JSON
- ドキュメント: https://info.gbiz.go.jp/api/index.html

## 設計上の判断（再発見コスト回避メモ）

### 認証 decorator は作らなかった
gBizINFO のトークンは静的なので `withBearerAuth` 相当の decorator は不要。`ApiClient.createClient({ headers: { 'X-hojinInfo-api-token': token } })` で十分。
継ぎ目（`request.headers` で上書き可能）は既に存在するため、将来動的トークンが必要になっても対応可能。

### apiVersion は固定（v1）
URL末尾の `v1` は現状1択。`apiVersion` をオプション化したくなるが、PHILOSOPHY §5.1 Rule of Three に従い、v2 が実際に出てから対応する（投機的一般化を避ける）。

### ドメインメソッドは `.use()` で呼び出し側に
`byCorporateNumber` / `search` 等はクライアント本体に生やさない。3プロジェクト目で同じパターンが現れた時にプラグイン昇格を検討（PHILOSOPHY §4.2 / §5.1）。

### プラグインファイル（`plugins/gbizinfo.ts`）は未作成
salesforce / slack には存在するが、gBizINFO は呼び出し側パターンが未確立のため作らない。需要が見えた時に追加。
